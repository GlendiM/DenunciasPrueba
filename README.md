# Buzon de Denuncias 
Proyecto Web para el manejo de denuncias de equidad en materia de géner, desarrollado en **Java 21**

--- 
## 🛠 Tecnologías 

- **Lenguaje:** Java 21
- **Framework:** Spring Boot 3.5.6
- **Base de datos:** PostgreSQL
- **IDE recomendado:** VS Code
- **Control de versiones:** Git / GitHub
- **Dependencias:** Maven
