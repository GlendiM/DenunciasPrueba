# Buzon de Denuncias - buzondenuncias

ETIQUETAS: | **SPRING BOOT 3.5.6** | **JAVA 21** | **POSTGRESQL 17** | **JWT (en desarrollo)**| **API REST** | **USO LOCAL** |

## 📝 Descripción
**Buzón de denuncias** es un sistema diseñado para la recepcion, gestión y seguimiento de denuncias relacionadas 
con situaciones de inequidad o violencia de género dentro de la Universidad Veracruzana.
Permite el registro de usuarios (o denuncias anónimas), captura de hechos, seguimiento del caso y notificaciones internas.

Actualmente el proyecto se encuentra en desarrollo, con planes para integrar autenticación mediante **JWT** y
despliegue en futuros entornos productivos.
